## Запуск проекта через Docker

### Предварительные требования
* Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/).
* Созданный файл `.env` в корне проекта (см. раздел "Переменные окружения").

### Шаги запуска

1. Откройте терминал в корневой папке проекта.
2. Выполните команду:
   ```bash
   docker compose up --build
   ```

При первом запуске Docker-контейнеру потребуется время, чтобы:
1. Скачать базовый образ Python и зависимости.
2. Автоматически скачать модель эмбеддингов и сконвертировать её в формат ONNX.
3. Автоматически построить векторную базу знаний из документов в папке `data/`.

Пожалуйста, дождитесь появления в терминале лога `Application startup complete` и сообщения о том, что сервер запущен.

### Доступ к приложению
После успешного запуска:
* Интерфейс пользователя (Streamlit): [http://localhost:8501](http://localhost:8501)
* Документация API (Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)

### Как остановить
Нажмите `Ctrl + C` в терминале или выполните:
```bash
docker compose down
```

## Переменные окружения

### Как настроить

1. В корне проекта найдите файл `.env.example`.
2. Скопируйте его и переименуйте в `.env`:
3. Откройте созданный файл `.env` любым текстовым редактором и заполните значения.

### Список переменных

| Переменная | Обязательная | Описание | Пример значения |
| :--- | :---: | :--- | :--- |
| `API_KEY` | Да | API-ключ для доступа к LLM (выдается на платформе TeamoRouter или OpenAI-совместимого провайдера). | `sk-1234567890abcdef...` |
| `BASE_URL` | Да | Базовый URL API для запросов к нейросети. | `https://api.teamorouter.com/v1` |
| `MODEL` | Да | Идентификатор языковой модели, которая будет генерировать ответы. | `claude-haiku-4-5` |
| `API_URL` | Нет | Адрес бэкенда для фронтенда (Streamlit). *Если вы запускаете через Docker, менять не нужно.* | `http://127.0.0.1:8000` |

### Пример файла `.env`

```env
# Ключ доступа к API (TeamoRouter)
API_KEY=sk-your-super-secret-key-here

# Базовый URL API
BASE_URL=https://api.teamorouter.com/v1

# Название модели
MODEL=claude-haiku-4-5
```

## Тестирование и покрытие

Проект покрыт автоматизированными тестами (с использованием `pytest` и `pytest-cov`). 
Покрытие прикладного кода превышает 80%.

### Как запустить тесты локально

1. Убедитесь, что установлены dev-зависимости:
```bash
   uv sync
```
2. Запустите тесты с отчётом о покрытии:
```bash
   uv run pytest --cov=backend
```

## Отчёт о покрытии тестами

### Как воспроизвести
Для запуска тестов и генерации отчёта выполните команду в корне проекта:
