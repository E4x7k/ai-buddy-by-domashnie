# SDD: Спецификация AI-buddy

## 1. Роль агента
AI-buddy — это корпоративный ИИ-ассистент, предназначенный для помощи стажерам в период адаптации. 
Основная задача — снизить когнитивную нагрузку на нового сотрудника и сэкономить время наставника.

## 2. Доступные сценарии
1. Вопрос-ответ по базе знаний: Поиск информации в документации собранной из открытых источников Авито (с указанием источников, на основе которыз был сформирован ответ).
2. Выполнение действий (MCP): Оформление заявок на отгул и запрос доступов к корпоративным инструментам (Jira, Confluence).
3. Трекинг адаптации: Визуализация прогресса стажера через интерактивный чек-лист.

## 3. Инструменты (MCP)
Агент имеет доступ к следующим инструментам (Functions / Tool Calling):
*   `request_vacation`: Принимает дату (`YYYY-MM-DD`) и причину. Вызывает API HR-системы, возвращает номер тикета.
*   `request_access`: Принимает название ресурса (например, `Jira`). Вызывает API Service Desk, возвращает номер тикета.

## 4. Ролевая модель и безопасность
Агент поддерживает две роли, которые передаются в каждом запросе (`user_role`):
*   `intern` (Стажер): Имеет полный доступ к базе знаний и инструментам (может оформлять отгулы и доступы).
*   `mentor` (Наставник): Имеет доступ к базе знаний и может просматривать прогресс стажера (чек-лист становится read-only), но не имеет права вызывать инструменты действий от имени стажера.

## 5. Ограничения и правила (System Prompt Rules)
*   Запрет галлюцинаций: Агент отвечает строго на основе переданного контекста. Если информации нет, он обязан сказать: "Я не нашел этой информации в базе знаний".
*   Формат ответа: Ответы должны быть краткими, структурированными (списки, таблицы) и без "воды".
*   Безопасность: Агент не раскрывает персональные данные сотрудников и не выполняет действия, выходящие за рамки описанных MCP-инструментов.

## 6. Архитектура и стек
*   LLM: Claude Haiku (через OpenAI-совместимый API TeamoRouter) с поддержкой стриминга и Tool Calling.
*   Векторная БД: ChromaDB + FastEmbed (`LaBSE-ru-turbo`).
*   Бэкенд: FastAPI (Python 3.12), SQLite (история и чек-лист).
*   Графический интерфейс: Streamlit.
